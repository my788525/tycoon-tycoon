# 发展国 · Tycoon Tycoon

**全复刻 Gamedev Tycoon（游戏发展国）· Web 端 2.5D 手账像素风 · 4 款换皮游戏**

## 游戏矩阵

| 游戏 | 域名 | 主题 |
|------|------|------|
| 🎮 游戏发展国 | `games/game/` | 开游戏工作室，立项发游戏，冲爆款，上市敲钟 |
| 💻 程序发展国 | `games/app/` | 程序员开软件公司，做 App / 小程序 / SaaS，拿融资 |
| 🤖 AI 发展国 | `games/ai/` | AI 实验室，训大模型、搭 Agent，算力烧钱风口轮转快 |
| 🎨 设计发展国 | `games/design/` | 设计工作室，做 UI / 品牌 / 国潮 IP，拿国际奖 |

## 核心玩法（全复刻 Gamedev Tycoon）

```
立项(GREENLIGHT) → 开发(DEVELOP) → 发行(SHIP) → 市场表现(PERFORM) → 下月
   ↑                                                        |
   └──────────── 循环经营 ←─────────────────────────────────┘
```

**功能清单：**
- ✅ 办公室租赁（4 档：车库→小型→大型→旗舰总部，影响容量+每月租金）
- ✅ 员工系统（4 岗位：开发/美术/产品/市场，招聘/升级/解雇，等级 1-5）
- ✅ 产品组合决策（平台×题材×受众×变现×体量，五维选择）
- ✅ 属性投入（玩法/画面/优化/内容 4 个滑杆，影响评分）
- ✅ 团队能力自动提升对应属性
- ✅ 发行统计（评分 0-10、首月销量、首月营收、衰减曲线 6 月）
- ✅ 随机事件（每 3 月抽签，本土化文案）
- ✅ 趋势系统（每 6 月轮转热点题材）
- ✅ 升级研究树（研发/营销/商业 三条线，前置依赖）
- ✅ 士气系统（影响评分，解雇降士气，随时间自然回复）
- ✅ 贷款系统（资金负数时可借，每月自动还款 50%）
- ✅ 破产结局（资金<0 且无贷款 → 破产清算）
- ✅ 4 个结局（大亨/传奇/顶流 IP/破产）
- ✅ 分享成果卡（Canvas 手绘，可下载 PNG）
- ✅ 存档/读档（localStorage，自动保存）

## 技术架构

```
common/
├── engine.js    # 纯逻辑引擎（回合制经济模拟，零 DOM）
├── profiles.js  # 4 域产品数据（换皮就加这里）
├── ui.js        # DOM 渲染 + Web Audio 音效 + 动画
├── core-ui.js   # 弹窗/胜利/分享/金币/彩带/存档
└── boot.js      # 启动器（读 data-domain 驱动引擎）
stylesheets/
└── tycoon.css   # 2.5D 手账像素风
games/
├── game/index.html
├── app/index.html
├── ai/index.html
└── design/index.html
index.html       # 4 游戏导航主页
```

**4 款游戏共用一套引擎，仅切换 profile 数据。**

## 本土化特色

- 资金单位：¥（人民币）
- 事件文案：版号/主播/大厂抄袭/A 轮融资/算法备案/国潮 IP
- 结局命名：游戏大亨/独角兽程序厂/AI 巨擘/设计帝国
- 办公室命名：车库→小型办公室→大型办公室→旗舰总部（按域定制）
